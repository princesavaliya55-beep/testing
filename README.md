# Kior Élite

Create a frontend-only premium redesign/demo of my existing Kior Perfume website using React + Vite.

Use my existing/uploaded Kior Perfume website as the content and product reference. Keep the existing Kior brand name, logo, perfume products, product names, collections, Pride collection, and important website content, but completely redesign the frontend into a high-end 2026 luxury fragrance e-commerce experience.

The final website should feel like a premium niche fragrance brand — elegant, editorial, emotional, sophisticated, minimal and visually impressive.

MAIN GOAL

Focus almost all effort on:

Premium UI/UX

Beautiful product presentation

Strong luxury branding

Responsive design

Smooth interactions

Functional shopping-demo experience

Do NOT spend credits building backend functionality or unnecessary technical infrastructure.

DESIGN DIRECTION

Create a visual style inspired by premium luxury fragrance and fashion houses.

Use a sophisticated palette:

Warm ivory / cream backgrounds

Soft champagne

Elegant blush / dusty rose accents

Deep black / charcoal typography

Small touches of muted gold where appropriate

Avoid excessive gradients, bright colors, generic SaaS styling, oversized rounded cards, or cheap-looking e-commerce layouts.

The website should feel:

Luxury + Editorial + Romantic + Minimal + Modern + Exclusive

Use generous whitespace and premium spacing.

TYPOGRAPHY

Use an elegant luxury serif font for:

Main hero headings

Important brand statements

Pair it with a clean modern sans-serif font for:

Navigation

Product information

Prices

Buttons

Forms

Small labels

Typography should feel similar to a premium perfume magazine/editorial website.
